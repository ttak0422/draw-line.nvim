*draw-line.txt*          Lines and automatic arrows              *draw-line*

Requires Neovim 0.10+ and a font that displays the drawing glyphs in one cell.

==============================================================================
API                                                        *draw-line-api*

All functions are on require("draw-line"). Styles apply only to each call;
omitting a style always uses single. No default mappings are installed.

Functions return true on success or nil, message if the edit cannot be made.
Invalid arguments, unknown style names and extra arguments raise an error.

draw({direction}, {style}?)                                 *draw-line-draw*
    Draw one edge and move one cell: h left, j down, k up, l right.
    A new start uses the style's horizontal or vertical straight glyph.
    The free tip is an automatic arrow; joining linework produces a junction.
    Repeat calls to extend or turn the line. See |draw-line-examples|.

box({start}, {finish}, {style}?)                             *draw-line-box*
    Positions are {row, col}: 1-based buffer rows and display columns.
    Draw the inclusive rectangle outline, accepting either corner order,
    and preserve the cursor. Same-row or same-column positions draw a stroke;
    one cell draws a crossing. Boxes do not add arrows.

box_visual({style}?)                                        *draw-line-box-visual*
    Draw the live Visual Block (<C-v>) outline. On success enter Normal mode
    at the top-left corner. Call while the selection is active; it must use
    selection=inclusive and a fixed end column rather than $.

STYLES                                                     *draw-line-styles*

    Name             Weight   Horizontal / vertical    Corners
    single           light       ─ / │                 ┌┐└┘
    heavy            heavy       ━ / ┃                 ┏┓┗┛
    double           double      ═ / ║                 ╔╗╚╝
    rounded          light       ─ / │                 ╭╮╰╯
    dashed2          light       ╌ / ╎                 ┌┐└┘
    dashed3          light       ┄ / ┆                 ┌┐└┘
    dashed4          light       ┈ / ┊                 ┌┐└┘
    heavy_dashed2    heavy       ╍ / ╏                 ┏┓┗┛
    heavy_dashed3    heavy       ┅ / ┇                 ┏┓┗┛
    heavy_dashed4    heavy       ┉ / ┋                 ┏┓┗┛

The suffix 2, 3 or 4 is the number of dashes per Unicode cell. Dashed styles
use solid corners and junctions of the same weight.

==============================================================================
EXAMPLES                                                   *draw-line-examples*

From an empty line: >lua
    local draw = require("draw-line")
    draw.draw("l", "dashed3")    -- ┄▶
    draw.draw("l", "dashed3")    -- ┄┄▶
<
Turn a line, starting on another empty line: >lua
    draw.draw("l", "rounded")
    draw.draw("l", "rounded")
    draw.draw("l", "rounded")
    draw.draw("j", "rounded")
    draw.draw("j", "rounded")
<
    ───╮
       │
       ▼

The arrow follows the free tip as the line extends or turns. Retracing existing
linework removes the arrow until a free end is reached again.

Draw a rectangle in a blank area: >lua
    draw.box({ 1, 1 }, { 3, 7 }, "double")
<
    ╔═════╗
    ║     ║
    ╚═════╝

EXPERIMENTAL DIAGRAM EDITOR                                 *draw-line-diagram*

An opt-in box/connector editor, separate from require("draw-line").
Neovim 0.10+; tested on stable 0.12.6. No nightly features are required.

Start in a disposable buffer, enabling mouse input and disabling wrap yourself:
>lua
    vim.cmd("enew")
    vim.o.mouse = "a"
    vim.wo.wrap, vim.wo.conceallevel = false, 0
    _G.diagram = assert(require("draw-line.diagram").attach())
<
attach() takes the current buffer and returns a session or nil, message.
It installs Normal-mode buffer-local LeftMouse/LeftDrag/LeftRelease/Esc
mappings. Attach fails if any already has a local mapping. Global mappings
are shadowed until detach. The plugin changes no editor options.

SELECT TOOL (default):
  Drag empty space for a rectangle (minimum 3 rows/3 columns). To overlap an
  object, start outside it and finish inside it, or move another box over it.
  Drag a visible box center (◆) to move its outline and attached connectors.
  Drag a visible segment midpoint (●) perpendicular to the line for bends.
  A straight segment gains bends. Short/hidden segments have no visible handle.
  Click an object to raise it. Moves/bends also raise their object. Selection
  is front-to-back; only the chosen object moves to the front, preserving the
  others' order. Release commits once, including a stacking-only change.
  There is no live preview. Esc cancels the gesture or pending connection.

CONNECT TOOL:
  diagram:set_tool("connect"), then click source and target boxes.
  Facing side centers are anchors. Initial routing needs at least 3 blank
  cells of separation on one axis. Picking endpoints does not reorder them;
  the new edge is frontmost. Return with diagram:set_tool("select").

OPAQUE LAYERS AND TEXT:
  Full box/edge geometry is retained even while hidden. Box interiors mask
  lower diagram geometry. Moving a box reveals the complete lower geometry.
  Edges and boxes share one back-to-front list. Box movement updates attached
  edges but only raises the box; untouched edges keep their relative order.
  Edge crossings do not add graph connections. No obstacle router is provided.

  Native text is a separate protected underlay: labels stay visible through
  interiors, and a new contour/connector touching them fails atomically.
  Labels remain in their buffer cells when a box moves. There is no label UI
  or association/transport. Use normal editing such as Replace mode to fill
  interior blanks without shifting drawing cells. Tabs, wide/composing Unicode,
  and unowned linework are protected. Editing an owned glyph or changing row
  count blocks operations until undone. No hidden text is guessed from glyphs.

SESSION API (1-based buffer rows and display columns):
  diagram:box({row, col}, {row, col})        -> box ID or nil, message
  diagram:connect(source_id, target_id)     -> edge ID or nil, message
  diagram:move(box_id, {row, col})          -> true or nil, message
      Destination is the new center. The box becomes frontmost.
  diagram:bend(edge_id, segment, {row,col}) -> true or nil, message
      Segment is a 1-based index in the simplified route and may change after
      edits. Mouse handles are the intended interface. The edge becomes frontmost.
  diagram:raise(object_id)                 -> true or nil, message
  diagram:set_tool("select" / "connect")    -> true or nil, message
  diagram:cancel()                         -> true
  diagram:inspect()                        -> graph copy or nil, message
  diagram:save()                           -> true, sidecar path or nil, message
  diagram:detach()                         -> true

Graph: boxes, edges, next_id, z_order (back-to-front IDs). A box has
id/top/bottom/left/right. An edge has id/source/target/source_side/target_side/
waypoints. Anchors derive from side centers. All graph reads/edits require the
session buffer to be current. Detach leaves text and removes only owned mappings.

SAVE/LOAD                                       *draw-line-diagram-persistence*
  First :write the ordinary text file. Then:
>lua
    assert(diagram:save())
<
  Explicitly writes <buffer filename>.draw-line.json. UTF-8 with unix/dos
  line endings is supported; the unmodified buffer must match file bytes.
  After reopening the text with compatible display settings:
>lua
    _G.diagram = assert(require("draw-line.diagram").load())
<
  load() returns a new session or nil, message. It validates schema version,
  saved text hash, references, limits, display settings, and exact projection
  before attaching. It never edits text. Detach before loading into a live
  session. attach() always starts empty and protects existing linework.

  The adjacent JSON sidecar carries the complete graph (including occluded
  geometry), original text underlay, stable document/object IDs, anchors,
  waypoints, z-order, revision, display settings, and saved text hash. Copy or
  rename BOTH files for portability. No machine-local cache is required.
  Save As writes the new path's sidecar and retains the old path's sidecar.
  Unknown existing sidecars are never overwritten by a newly attached session.

  Missing, malformed, unknown-version, or mismatched sidecars stop loading.
  External text/metadata changes and existing writer locks stop saving. Invalid
  references/oversized data are rejected. No automatic merge or recovery.
  Sidecar replacement uses an exclusive writer lock, flushed temporary file,
  and atomic rename. Failed preparation/rename preserves prior metadata and
  cleans only this save's temporary files. An orphaned lock needs inspection;
  the plugin never removes another writer's lock.
  Text :write and sidecar save are separate operations, not an atomic pair.
  A crash/failure between them can leave a mismatch, which load refuses. Keep
  a live session after a save error and retry; no text rollback is performed.
  Sidecars and text must be regular files of at most 4 MiB. No code is executed
  from JSON. Transparency/line-style options are not part of this schema yet.

UNDO:
  Operations, including metadata-only raises, create native undo blocks.
  Native label edits inherit the correct diagram snapshot on their own undo
  branch, including counted undo/redo. Unknown/pruned ancestry stops editing.
  Underlay and z-order follow the same snapshot as geometry. Undo must be enabled.
  Loading establishes a new session baseline; prior-session graph undo history
  is not imported from a native undofile. Undoing before a known baseline can
  stop diagram editing until redone or detached.

MOUSE AND LIMITS:
  Requires nowrap, left-to-right, no conceal/diff or closed visible folds.
  Number/sign gutters, split windows, winbars, and vertical/horizontal scroll
  work. Blank space below EOF can extend the buffer. Inline virtual text/lines,
  autoscroll, and dragging between windows are unsupported.
  Scrolling/resizing/editing/Insert/leaving the original window cancels a drag.
  Clicks into another split use native mouse navigation; external release of
  a diagram drag cancels without editing either buffer.
  500 by 500 cells, 100 objects, 10,000 total layer cells including opaque and
  hidden cells, 128 waypoints per edge, single-weight lines. No resize/delete,
  arrowheads, label transport, transparency picker, general obstacle routing,
  draw.io import, or Hydra integration. Actual terminal mouse/tmux/font behavior
  remains unverified. Tests use isolated UI events and fresh-process reopening.
