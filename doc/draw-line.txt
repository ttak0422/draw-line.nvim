*draw-line.txt*          Lines and automatic arrows              *draw-line*

Requires Neovim 0.10+ and a font that displays the drawing glyphs in one cell.

==============================================================================
API                                                        *draw-line-api*

All functions are on require("draw-line"). Styles apply only to each call;
omitting a style always uses single. No default mappings are installed.

Functions return true on success or nil, message if the edit cannot be made.
Invalid arguments, unknown style names and extra arguments raise an error.

draw({direction}, {style}?)                                 *draw-line-draw*
    Draw one edge and move one cell: h left, j down, k up, l right.
    A new start uses the style's horizontal or vertical straight glyph.
    The free tip is an automatic arrow; joining linework produces a junction.
    Repeat calls to extend or turn the line. See |draw-line-examples|.

box({start}, {finish}, {style}?)                             *draw-line-box*
    Positions are {row, col}: 1-based buffer rows and display columns.
    Draw the inclusive rectangle outline, accepting either corner order,
    and preserve the cursor. Same-row or same-column positions draw a stroke;
    one cell draws a crossing. Boxes do not add arrows.

box_visual({style}?)                                        *draw-line-box-visual*
    Draw the live Visual Block (<C-v>) outline. On success enter Normal mode
    at the top-left corner. Call while the selection is active; it must use
    selection=inclusive and a fixed end column rather than $.

STYLES                                                     *draw-line-styles*

    Name             Weight   Horizontal / vertical    Corners
    single           light       ─ / │                 ┌┐└┘
    heavy            heavy       ━ / ┃                 ┏┓┗┛
    double           double      ═ / ║                 ╔╗╚╝
    rounded          light       ─ / │                 ╭╮╰╯
    dashed2          light       ╌ / ╎                 ┌┐└┘
    dashed3          light       ┄ / ┆                 ┌┐└┘
    dashed4          light       ┈ / ┊                 ┌┐└┘
    heavy_dashed2    heavy       ╍ / ╏                 ┏┓┗┛
    heavy_dashed3    heavy       ┅ / ┇                 ┏┓┗┛
    heavy_dashed4    heavy       ┉ / ┋                 ┏┓┗┛

The suffix 2, 3 or 4 is the number of dashes per Unicode cell. Dashed styles
use solid corners and junctions of the same weight.

==============================================================================
EXAMPLES                                                   *draw-line-examples*

From an empty line: >lua
    local draw = require("draw-line")
    draw.draw("l", "dashed3")    -- ┄▶
    draw.draw("l", "dashed3")    -- ┄┄▶
<
Turn a line, starting on another empty line: >lua
    draw.draw("l", "rounded")
    draw.draw("l", "rounded")
    draw.draw("l", "rounded")
    draw.draw("j", "rounded")
    draw.draw("j", "rounded")
<
    ───╮
       │
       ▼

The arrow follows the free tip as the line extends or turns. Retracing existing
linework removes the arrow until a free end is reached again.

Draw a rectangle in a blank area: >lua
    draw.box({ 1, 1 }, { 3, 7 }, "double")
<
    ╔═════╗
    ║     ║
    ╚═════╝

==============================================================================
EXPERIMENTAL DIAGRAM EDITOR                                 *draw-line-diagram*

An opt-in, in-memory box/connector editor, separate from require("draw-line").
Neovim 0.10+; tested on stable 0.12.6. No nightly features are required.

Start in a disposable buffer, enabling mouse input and disabling wrap yourself:
>lua
    vim.cmd("enew")
    vim.o.mouse = "a"
    vim.wo.wrap, vim.wo.conceallevel = false, 0
    local diagram = assert(require("draw-line.diagram").attach())
<
attach() takes the current buffer and returns a session or nil, message.
It installs Normal-mode buffer-local LeftMouse/LeftDrag/LeftRelease/Esc
mappings. Attach fails if any of these already has a local mapping. Global
mappings are temporarily shadowed. The plugin sets no editor options.

SELECT TOOL (default):
  Drag empty space to make a rectangle (minimum 3 rows and 3 columns).
  Drag a box's exact center (◆) to move its outline and connected edges.
  Drag a segment midpoint (●) perpendicular to the segment to adjust bends.
  Dragging a straight segment inserts bends. Short segments have no handle.
  Coincident handles select the older edge; box centers take priority.
  A release commits once. There is no live drag preview.

CONNECT TOOL:
  Call diagram:set_tool("connect"), then click a source and a target box.
  An initial route joins facing side centers with orthogonal segments. Boxes
  need at least 3 blank cells of separation on one axis. Switch back with
  diagram:set_tool("select"). Esc cancels the pending source or gesture.

SESSION API (all coordinates are 1-based rows and display columns):

  diagram:box({row, col}, {row, col})       -> new box ID or nil, message
  diagram:connect(source_id, target_id)    -> new edge ID or nil, message
  diagram:move(box_id, {row, col})         -> true or nil, message
      The destination is the box's new center.
  diagram:bend(edge_id, segment, {row,col})-> true or nil, message
      Segment is a 1-based index in the current simplified orthogonal route.
      Mouse handles are the intended interface; indices can change after edits.
  diagram:set_tool("select" / "connect")   -> true or nil, message
  diagram:cancel()                        -> true
  diagram:inspect()                       -> graph copy or nil, message
  diagram:detach()                        -> true

The graph has boxes, edges, and next_id. Each box has id/top/bottom/left/right.
Each edge has id/source/target/source_side/target_side/waypoints. Anchors are
derived from side centers. Waypoints use buffer cells; attached terminal
segments follow moved boxes. These are experimental structures, not a saved
file format. Methods that read or edit the graph require its buffer to be
current. Detach retains plain text and removes only the session's own mappings.

SAFETY AND UNDO:
  One operation, including all connected edges, is one native undo/redo step.
  Graph snapshots follow native undo sequence numbers while the session lives.
  Native text edits inherit the nearest diagram snapshot on their undo branch,
  including counted undo/redo. Missing/pruned ancestry blocks further editing.
  Undo must be enabled. Unrelated cells remain byte-identical. New drawing may
  replace only blank cells or cells already owned by this session. It never
  adopts existing linework, including drawings made by the original API.
  A change to an owned glyph, a shift of its display position, or a buffer row
  count change blocks editing: undo that edit or detach before continuing.
  Other native text edits are allowed if all owned glyphs stay in place.
  For labels, use Replace mode to fill interior blanks without shifting edges.
  Labels remain in their original cells when a box moves; they are not objects.

MOUSE COORDINATES:
  Requires nowrap, left-to-right, no conceal/diff, and no closed visible folds.
  Number/sign gutters, split windows, and horizontal/vertical scroll work.
  Gestures cancel when scrolled/resized, edited, entering Insert mode, leaving
  their window/buffer, or released outside the original supported text area.
  Empty space below EOF can extend the buffer. Inline virtual text and virtual
  lines are unsupported. No autoscroll or dragging between windows.
  Clicks in another split use native mouse behavior to switch focus; a diagram
  drag released outside its original window cancels without editing either buffer.

POC LIMITS:
  500 by 500 display cells; 10,000 drawing cells; single-weight line style.
  Boxes cannot overlap/share cells. Edges can cross: a visual junction does
  not add a connection in the graph. A route crossing any box beyond its own
  anchor is rejected, without edits. There is no general obstacle router.
  No object resize/delete, arrowheads, label UI/transport, persistence/import,
  or draw.io integration. A no-visible-change operation is rejected.
  Saving writes plain text. The object model and undo snapshots disappear on
  detach, wipeout, opening a new buffer, or restarting. To freehand-edit with
  the original drawing API, detach first. Reattach starts with an empty graph
  and protects old linework. Actual terminal/font appearance is unverified;
  tests use a separate embedded Neovim with a real UI grid and mouse events.
